feat(proxy): 1.1.0 ships its own main-process service

The proxy feature no longer runs inside the application: config generation, core
lifecycle, node store access, geo handling and system-proxy control all live here now,
exposed through the host's generic `mod:invoke` bridge.

  plugins/proxy/main/       main-process half (config.ts, manager.ts, handlers)
  plugins/proxy/vite.main.config.ts   builds it to CJS at dist/main/index.js
  plugins/proxy/src/        UI, now calling its own service via window.api.mod

The package zip contains dola-mod.json, index.js and main/index.js; the app loads the
service on install, so no restart is needed.

README documents the `register(dola)` contract and the host API it receives.
