feat(livepet): 1.1.0 — 悬浮球 with vision / listen / chat / settings

The ball that operates the pet: a 240x60 desktop window holding a collapsed 44px disc that
expands into grip / 识屏 / 听音 / 聊天 / 设置. It is dragged through the host so it never
takes focus from the desktop.

than owning a key, and the screenshot is captured with desktopCapturer in the main process.
