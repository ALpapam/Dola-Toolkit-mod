feat(livepet): 桌宠 plugin — Live2D on the desktop (1.0.0)

Renders a Cubism 4 model in the transparent desktop window the host provides.

  plugins/livepet/src/stage.ts   pixi-live2d-display wrapper: fit, bottom anchor
  plugins/livepet/src/pet.ts     the desktop page: load, report hit box, toggle passthrough
  plugins/livepet/main/index.ts  model import (skips .cmo3/.psd), show/hide, size, on-top

The hand-written WebGL renderer I tried first could not reproduce Cubism's mask and clip
passes — the Core exposes vertex data but not the draw matrices — so the plugin uses the
library that implements them. Core is loaded synchronously in pet.html because
pixi-live2d-display inspects window.Live2DCubismCore while its module body evaluates.

README documents the new host surface: dola.desktop, dola.dialog.pickDirectory and the
dola-mod://<id>/@data/ data route.
